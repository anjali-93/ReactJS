Introduction -- Basically this is a Employee Management System where you can see the details about the employee Edit/ delete and print the list of Employees - 

LOGIN PAGE : It has login page which only login by admin if you used other than admin it shows INVALID CREDENTIALS and after login the pagin you redirect the dashboard. 

Tech Stack Used :

React.js
React Router DOM 
Tailwind CSS 
JavaScript (ES6+)
LocalStorage 
Vite 

DASHBOARD : In the Dashboard, 
-> First You see the SEARCH by the NAME , GENDER OR ACTIVE OR INACTIVE . 
-> Below the search bar you can see the ADD EMPLOYEE option, where you can add the Employee data to the list.
-> After that you can see the table where all the Employees have been listed it has EDIT/DELETE/PRINT option you can used these .
